# Poll Result Visualizer

A simple and interactive web application to create polls and visualize voting results using dynamic charts and graphs. This project helps users easily understand poll outcomes with real-time percentage distribution and graphical insights.

---

## 🚀 Features

* 📊 Real-time poll result visualization
* 🗳️ Create and manage polls
* 📈 Dynamic charts using graphical libraries
* 🎨 Clean and responsive UI
* ⚡ Fast and lightweight application
* 📱 Mobile-friendly design

---

## ⚙️ Installation & Setup

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/your-username/Poll-Result-Visualizer.git
```

### 2️⃣ Navigate to Project Folder

```bash
cd Poll-Result-Visualizer
```

### 3️⃣ Create Virtual Environment

```bash
python -m venv venv
```

### 4️⃣ Activate Virtual Environment

#### Windows

```bash
venv\Scripts\activate
```

#### Mac/Linux

```bash
source venv/bin/activate
```

### 5️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

---

## ▶️ Run the Application

```bash
python app.py
```

The application will start on:

```bash
http://127.0.0.1:5000
```

## 📊 How It Works

1. Users create a poll with multiple options
2. Participants cast their votes
3. Votes are processed instantly
4. Results are displayed through interactive charts and percentage analysis
